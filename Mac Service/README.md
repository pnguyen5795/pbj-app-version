# PB&J on your Mac

This folder contains the launchers for the personal iPhone app's Mac service. They use this workspace's existing registry and private configuration. They do not install a website or a hosted service.

## Start, check and stop

1. Double-click **Start PBJ.command**. Leave the Terminal window open. Its startup message says whether AI processing is enabled or paused.
2. Open **PB&J** on the iPhone and choose **Use Local Workspace**. Allow Local Network access and keep both devices on the same home network.
3. Double-click **Check PBJ.command** to inspect the encrypted connection, pairing, running and saved AI modes, and jobs.
4. Double-click **Stop PBJ.command** before quitting Terminal. It requests a graceful stop after the current operation.

Start reads the saved `aiProcessingEnabled` setting. When enabled, API and worker start together; saved queued requests resume using existing analyses and provider responses where available. New work can make **paid TwelveLabs/OpenAI requests**. When paused, project access remains available without the worker. Stopping the Mac does **not** cancel processing already accepted by a provider. Use live status checks for current activity; this README is not a task inventory.

Start again after restarting your Mac; launch at login is not configured. The launcher prevents idle sleep while running. Keep the Mac plugged in and its lid open; closing the lid or selecting Sleep can still interrupt the connection.

Normal phone-to-Mac traffic uses the home network. A cable is used for initial installation/pairing and when needed for app updates. The configured installation uses your Mac's `.local` hostname on port `8788`; changing the Mac's name requires updating its certificate and phone pairing.

## Using the app

**My Projects → Continue setup** reopens an unfinished recipe. **Let's cook!** uploads originals to the Mac; enabled AI processing sends analysis media to TwelveLabs and editing context to OpenAI. The resulting timeline returns to the iPhone for preview, manual editing and local export. Automatic captions are deferred and hidden.

The personal service uses one shared dummy workspace. Another phone needs installation and pairing, and will share the Mac's projects/media rather than have an independent account.

If disconnected, check that Start's Terminal window shows the service ready, the Mac is awake, both devices are on the home network, and iPhone Local Network access is allowed. A Terminal window ending with **Process completed** is not a running service; inspect the error above it. If an Oh My Zsh update prompt consumed the launcher path, dismiss that prompt before opening Start again. Manual edits to already-local projects do not require the Mac; server-backed approval and synchronization do.

## Storage and recovery

- **iPhone:** imported originals, editable projects, exports and device-only Keychain pairing.
- **Mac:** originals, analysis receipts, learning and queued jobs in `server/data/native`; credentials are read from the existing private environment file.
- **Providers:** media/context submitted for the requested AI processing.

Pairing uses a private token and a pinned HTTPS certificate, including hostname and expiry validation. Certificates generated by setup last 365 days and require renewed pairing when replaced. No global certificate trust or router forwarding is needed for this setup.

Private files in `server/data/personal-service` are ignored by Git. Do not share its configuration, pairing JSON or private key. The launchers contain no credentials but refer to machine-specific paths; keep the workspace in place or migrate and regenerate them deliberately.

Only one process may open the local registry. Stop the service and back up its data before direct database inspection or repair. Preserve originals, full provider responses and task IDs. Older receipts known only to the legacy inventory require reconciliation before new baseline analysis; never clear the registry to bypass that safeguard.

The Mac-only adapter currently supports direct uploads of analysis derivatives up to 200 MB. Larger derivatives are not supported by this personal configuration yet; native resumable provider uploads are the planned fix. Do not automatically resubmit an uncertain paid request to recover a failed job. See the [fix plan](../docs/FIX_PLAN.md) for remaining workload and acceptance checks.
